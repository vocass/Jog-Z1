# Jog-Z1
Controller with a scroll wheel for the Z1 machine
The device is compatible only with the Comunit controller. Makera Studio does not support it. The firmware is based on the WHB04B pendant. It also includes another program for the C500 from NestWorks, which has not yet been tested; it is designed for machines with CNC GRBL.
This is my first project on GitHub. I apologize in advance for any mistakes or a disorganized description.
